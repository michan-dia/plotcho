# プロット帖 使いかた

漫画のプロットを、セリフやモノローグのカードで組み立てるアプリです。
カードを並べ替えながら話の流れを考え、できたセリフはCLIP STUDIO PAINTのストーリーエディターにそのまま流し込めます。

スマホ・タブレット・PCのどれでも使えます。

![プロット帖の画面](docs/screenshots/01-overview.png)

---

## はじめかた

アプリのページを開くと、すぐに使えます。最初は「雨宿りの花屋(サンプル)」という作品が入っています。そのまま触って試すか、上の帯の「空のプロットを作る」で新しく始めてください。

### ホーム画面・アプリ一覧に追加する

追加しておくと、アプリのように直接起動できます。一度開いたあとは、ネットにつながっていなくても起動して書けます。

| 端末 | 追加のしかた |
| --- | --- |
| iPhone・iPad(Safari) | 共有ボタン →「ホーム画面に追加」 |
| Android(Chrome) | 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」 |
| PC(Chrome・Edge) | アドレスバーの右にあるインストールのボタン |

PC版(インストールするタイプ)を使っている場合は、デスクトップやスタートメニューの「プロット帖」から起動します。

## カードを書く

セリフ・モノローグ・ナレーション・ト書きを、1枚ずつカードに書きます。カードは、仕上がりのフキダシに近い形で表示されます。

| 種類 | 見た目 | ストーリーエディターへの書き出し |
| --- | --- | --- |
| セリフ | 丸いフキダシ | 入る |
| モノローグ | 点線の枠 | 入る |
| ナレーション | 四角い枠 | 入る |
| ト書き・メモ | 黄色い付箋 | 入らない(演出のメモ用) |

### 書く・直す

カードを押すと、青い枠が付いて書けるようになります。ほかの場所を押すと終わります。

![カードを編集しているところ](docs/screenshots/02-card-edit.png)

- **Enterを1回**押すと、同じカードの中で改行します(2行のセリフなど)。
- **Enterを2回**押すと、すぐ下に次のカードができて、そのまま続けて書けます。セリフの話者は、2人のあいだで交互に切り替わります。
- 文章の途中でEnterを2回押すと、そこから後ろが次のカードに分かれます。
- 区切りのいちばん下にある「＋ セリフ」「＋ モノローグ」などのボタンでも追加できます。

### 「⋯」と「×」

カードの右上に「⋯」と「×」が出ます。PCではカードにマウスをのせたとき、スマホ・タブレットではカードを押して書いているときに出ます。

![カードの右上のボタン](docs/screenshots/24-card-tools.png)

- **×**: カードを削除します。削除したあと、画面の下に出る「元に戻す」を押すと戻せます。
- **⋯**: 種類と話者の変更、下にカードを追加、複製、伏線、削除ができます。

カードの左上の小さな丸は、話者のキャラの色です。PCでは、カードにマウスをのせると話者と種類が表示されます。

### 種類と話者を変える

カードの「⋯」を押すと、上に「種類」と「話者」が出ます。選ぶとすぐに変わります。

![種類と話者を選ぶ](docs/screenshots/03-card-meta.png)

## カードを並べ替える

カードそのものをつかんで、好きな場所に動かします。別のシーンや別の区切りへも移せます。

- **PC**: カードをつかんで(マウスのボタンを押したまま)動かします。
- **スマホ・タブレット**: カードを少し長めに押すと持ち上がります。そのまま指を動かして、置きたい場所で離します。長押しせずに指を動かすと、普通のスクロールになります。
- 持ち上げたカードは少し浮いて見え、置く場所には青い点線の枠が出ます。
- **画面の外へ動かすとき**: つかんだまま画面の端(左右・上下)に近づけると、その方向へ自動でスクロールします。端に近いほど速く流れ、指やマウスを止めていても流れ続けます。目的の区切りが見えたら、端から離して置きます。

## 複数のカードをまとめて動かす

いくつかのカードを選んで、まとめて移動・削除できます。

![カードを選んでいるところ](docs/screenshots/25-select.png)

**選びかた**
- 上の「選択」ボタンを押すと選択モードになります。カードを押すたびに、選ぶ・外すが切り替わります(選んだカードには ✓ が付きます)。
- PCでは、選択モードにしなくても **Ctrl**(Macは **⌘**)を押しながらクリックで選べます。
- **Shift** を押しながらクリックすると、直前にクリックしたカードからそこまでをまとめて選びます(はじめのカードは普通にクリックするだけで大丈夫です)。

**選んだあと**(画面の下に出るバーから)
- **移動…**: 区切りとシーンの一覧から移動先を選ぶと、選んだカードがそのシーンのいちばん下に入ります。並び順はそのままです。スマホで遠くの区切りへ動かすときに便利です。
- **新しいシーンに**: 選んだカードを新しいシーンにまとめます。シーン名を入れてください。
- **削除**: 選んだカードをまとめて削除します。
- **×**(またはEscキー): 選択をやめます。

選んだカードのどれか1枚をつかんでドラッグすると、選んだカード全部がいっしょに動きます(つかんでいるカードに枚数が出ます)。
移動・削除・新しいシーンにしたあとは、画面の下の「元に戻す」で戻せます。

---

## 区切り(起承転結)

起・承・転・結のように、カードをまとめるいちばん大きな枠です。横に並びます。

- 名前は、見出しの文字を押して自由に変えられます。
- 「＋ 区切りを追加」で、いくつでも増やせます。
- 見出しの「◯P」に、その区切りの予定ページ数を入れます。
- 見出しの左の「⋮⋮」(または見出しの空いているところ)をつかむと、区切りごと並べ替えられます。スマホでは少し長めに押してから動かします。見出しの「⋯」の「ひとつ前へ移動」「ひとつ後ろへ移動」でも動かせます。
- 見出しの「⋯」から、色の変更・シーンの追加・前後への区切りの追加・削除ができます。
- 上の「横に並べる」「縦に並べる」で、区切りの並べ方を切り替えられます。

---

## シーン

区切りの中を、さらにシーンごとに分けられます。シーンは区切りの中で縦に並び、その中にカードが入ります。

![区切りの中のシーン](docs/screenshots/22-scenes.png)

- **作る**: 区切りのいちばん下の「＋ シーン」を押して、シーン名を入れます。
- **カードを入れる**: カードをシーンの中へドラッグします。空のシーンでは「＋ セリフ」でも追加できます。シーンの中でEnterを2回押すと、同じシーンの中に次のカードができます。区切りの下の「＋ セリフ」などで追加したカードは、いちばん下のシーンに入ります。
- **並べ替える**: シーン名の左の「⋮⋮」をつかむと、シーンごと動かせます。ほかの区切りへも移せます(転のシーンを承へ、など)。
- **たたむ**: シーン名の左の「▼」を押すと、カードを隠して1行にできます。もう一度押すと開きます。長いプロットの見通しをよくしたいときに使います。
- **シーンの「⋯」**: カードの追加、たたむ・開く、下にシーンを追加、上下や前後の区切りへの移動、削除ができます。

![シーンのメニュー](docs/screenshots/23-scene-menu.png)

シーンが1つしかなく名前もない区切りでは、シーンの枠は表示されません(今までどおりの見た目です)。
「まとめて入力」で「新しいシーン名」を入れると、入力したカードを新しいシーンとしてまとめて追加できます。

---

## まとめて入力

先に文章で書いておいたセリフを、まとめてカードにできます。上の「まとめて入力」を押します。

![まとめて入力](docs/screenshots/05-bulk.png)

- 空行を1行はさむと、そこで別のカードに分かれます。何枚に分かれるかが下に表示されます。
- 次の書き方をすると、話者と種類を自動で振り分けます。

| 書き方 | なるカード |
| --- | --- |
| `湊「おはようございます」` | 湊のセリフ |
| `久世：……おう` | 久世のセリフ |
| `(今日は、いつもより早い)` | モノローグ |

- 話者に「交互」を選ぶと、1人目と2人目のセリフが交互になります。

## ページ数を確かめる

タイトルの下の「全◯P」に、作品全体の予定ページ数を入れます。区切りごとの予定ページ数が、色分けのバーで表示されます。

![ページ数のバー(オーバーしているところ)](docs/screenshots/06-budget.png)

- 合計が予定を超えると、超えた分が赤い斜線になり、「◯Pオーバー」と表示されます。はみ出した区切りのページ数の欄も赤くなります。
- 足りないときは「残り◯P」、ちょうどのときは「ぴったり」と表示されます。

---

## 温度グラフ(二人の距離感)

シーンごとに、二人の距離感を0〜10で付けて、折れ線で表示します。告白や関係の成立をどこに置くか、いちゃいちゃの見せ場がどこにあるかを、グラフの形で確かめられます。

![温度グラフ](docs/screenshots/07-temp.png)

- 点はシーンごとに1つです。下にシーン名、その下に区切りの名前が色付きの線で出ます。シーンに分けていない区切りは、区切りごとに1つの点になります。
- 点を上下にドラッグして付けます。まだ付けていないシーンは、下に点線の丸が出ています。PCでは、点を選んで ↑↓ キーでも動かせます。
- いちばん高いシーンには丸い印が付き、上に「いちばん近いのは『最初の金曜日』(10)」のように表示されます。
- シーンを並べ替えたり別の区切りへ移したりすると、点もいっしょに移ります。
- 付けた点を消すときは、シーンの「⋯」→「グラフの点を消す」を選びます。区切りの「⋯」からは、その区切りの点をまとめて消せます。
- 上の「温度グラフ」ボタンで、表示・非表示を切り替えます(スマホでは、最初は閉じています)。

### グラフの名前を変える

左上の「二人の距離感」の文字を押すと、名前を書き換えられます。「緊張感」「すれ違い度」など、作品に合わせて使ってください。
横の「10＝」「0＝」の欄で、グラフの上と下の言葉(最初は「近い」「遠い」)も変えられます。名前は作品ごとに保存され、PNG・PDFの書き出しにも使われます。

## 伏線チェック

伏線を「張る」カードと「回収」するカードを指定しておくと、回収し忘れを見つけられます。

1. カードの「⋯」→「伏線を付ける…」を選びます。
2. 新しい伏線の名前を入れて「張る」を押すか、すでにある伏線の「張る」「回収」を押します。
3. カードの下に、どの伏線かが表示されます。◇は張る、◆は回収です。

![伏線が付いたカード](docs/screenshots/10-fs-tag.png)

伏線の一覧は「資料を横に出す」→「伏線」タブで見られます。

![伏線の一覧](docs/screenshots/08-side-fs.png)

| 表示 | 意味 |
| --- | --- |
| 回収済み | 張って、そのあとで回収している |
| 未回収 | 張ったまま回収していない |
| 張っていない | 回収だけあって、張る場所がない |
| 回収が先 | 張るより前の場所で回収している |
| 未使用 | どのカードにも付いていない |

- 「張る」「回収」の横の場所を押すと、そのカードへ移動します。
- 未回収の数は、「資料を横に出す」ボタンにも赤く表示されます。

## ネタ帳

思いついたことを、とりあえず書いておく場所です。作品ごとにあります。

![ネタ帳](docs/screenshots/26-memo.png)

- 上の「ネタ帳」ボタンを押すと、横(スマホでは下)にネタ帳が開いて、すぐに書けます。
- 書いて **Enter** を押すと追加されます。改行したいときは **Shift+Enter** です。新しいものが上に並び、書いた日時が付きます。
- 書いたネタを押すと、書き直せます。
- ネタはそのままカードとして使えます。
  - **ドラッグ**: ネタをつかんで、プロットの好きな場所へ置きます。
  - **⋯ →「プロットへ移動」**: 区切りとシーンを選ぶと、そのシーンのいちばん下に入ります(スマホではこちらが便利です)。⋯ では、種類(セリフ・モノローグなど)も変えられます。
- 逆に、プロットのカードをネタ帳へ戻すこともできます。カードの「⋯」→「ネタ帳へ戻す」を選ぶか、カードをネタ帳へドラッグします。
- ネタ帳に置いたものは、クリスタ用テキストやPNG・PDFの書き出しには入りません。

## キャラと作品の設定

上の「キャラ・設定」タブで書きます。

![キャラ・設定タブ](docs/screenshots/11-chars.png)

### キャラ

- 名前・よみ・立ち位置・年齢・身長・一人称・相手の呼び方・性格・外見・設定・メモを書けます。
- 画像は何枚でも入れられます。左の枠を押すか、画像をドラッグ&ドロップします。小さい画像を押すと大きく表示され、「メイン画像にする」「削除」ができます。
- 名前の横の色は、プロットの話者の色にも使われます。
- 「⋮⋮」をつかむと、キャラの順番を並べ替えられます。

### 作品の設定

能力の決まりごと、世界観、舞台、関係の前提など、作品ごとの設定を書いておく場所です。

![作品の設定](docs/screenshots/12-notes.png)

## 書き出し

右上の「書き出し」(スマホでは ⇩)から選びます。

![書き出しのメニュー](docs/screenshots/13-export-menu.png)

### クリスタ用テキスト

カードの順にテキストを並べて、カードごとに空行を1行はさみます。

![クリスタ用テキスト](docs/screenshots/14-text-export.png)

- 「コピー」してストーリーエディターに貼るか、「.txt で保存」してストーリーエディターで読み込みます。
- 「含めるカード」で、書き出す種類を選べます(ト書き・メモは最初から外してあります)。
- 「区切り・シーンの見出しを入れる」「話者名を付ける」は確認用です。見出しは「■起」「□雨宿り」のように入ります。ストーリーエディターに入れるときは外してください。

### PNG・PDF

編集さんに見せるときや、印刷して見直すときに使います。

![PNG・PDFの書き出し](docs/screenshots/15-png-pdf.png)

- 「プロット」「キャラ・設定」「両方」から選べます。
- プロットは「一覧(上から読む)」と「ボード(見たまま)」の2つの見た目から選べます。
- シーン名と伏線の一覧も入ります。
- 温度グラフは「入れるもの」のチェックで、入れるかどうかを選べます。選んだ設定は次回も使われます。
- PDFはA4サイズで、カードの途中でページが切れないように分けます。

## 作品の管理とバックアップ

作品名の横の「⋯」から行います。作品の切り替えは、作品名の欄で選びます。

![作品のメニュー](docs/screenshots/16-project-menu.png)

- **新しい作品** / **この作品を複製** / **この作品を削除**(削除は元に戻せません)
- **バックアップを保存(全作品)**: すべての作品を1つのファイルに保存します。キャラの画像も入ります。
- **バックアップを読み込む**: 保存したファイルから作品を取り込みます。今ある作品は消えずに、追加されます。

書いたものは、自動でその端末の中に保存されます。右上の「保存済み」がその合図です。

## 端末どうしの同期(Googleドライブ)

右上の「ドライブにつなぐ」を押してGoogleアカウントでログインすると、ほかの端末と同じ作品を編集できます。

![ドライブにつなぐボタン](docs/screenshots/17-sync-button.png)

- 一度つなぐと、編集するたびに自動で同期します。アプリを開いたときや、ほかのアプリから戻ってきたときにも同期します。ボタンには「同期済み 1:05」のように最後に同期した時刻が出ます。
- ブラウザ・ホーム画面版では、ログインが1時間ほどで切れます。「再接続」になったら押してください。それまでに書いた分は、端末の中に保存されています。PC版は、一度ログインすれば続けて使えます。
- データはGoogleドライブの「アプリ専用の場所」に入ります。ドライブの画面には表示されません。
- 同じ作品を2台で同時に書き換えた場合は、あとから保存したほうが残ります。
- ログインできるのは、アプリを置いた人がテスト用に登録したGoogleアカウントだけです。
- 「ドライブにつなぐ」が出ていない場合や、つながなくても、その端末の中に保存して使えます。

## 困ったとき

**書いたものが見当たらない**
別の端末で書いた場合は、ドライブにつないで同期すると表示されます。ブラウザの閲覧データを消すと、その端末の中のデータも消えます。こまめに「バックアップを保存」しておくと安心です。

**スマホでカードが動かない**
指を動かす前に、少し長めに押してください。すぐに動かすとスクロールになります。

**Enterを押すと文字の変換が確定するだけで、次のカードにならない**
日本語の変換中のEnterは、確定にだけ使われます。確定したあとに、Enterを2回押してください。

**「新しい版があります」と出た**
「切り替える」を押すと、最新の版になります。書いている内容はそのまま残ります。

**PC版のインストーラーを開くと「WindowsによってPCが保護されました」と出る**
個人で作ったアプリなので、毎回この確認が出ます。「詳細情報」を押してから「実行」を押してください。
