# プロット帖

漫画のプロットを、セリフやモノローグのカードで組み立てるアプリです。
カードを並べ替えながら流れを考え、できあがったセリフはCLIP STUDIO PAINTのストーリーエディターにそのまま流し込めます。

スマホ・タブレット・PCのどれでも使えます。ホーム画面に追加すれば、アプリのように起動できます。

---

## はじめかた

1. アプリのページを開きます。
2. ホーム画面に追加します(なくても使えます)。
   - **iPhone・iPad(Safari)**: 共有ボタン →「ホーム画面に追加」
   - **Android(Chrome)**: 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
   - **PC(Chrome・Edge)**: アドレスバーの右にあるインストールのボタン
3. 最初はサンプルの作品が入っています。そのまま触って試すか、「空のプロットを作る」で新しく始めます。

一度開いたあとは、ネットにつながっていなくても起動して書けます。

---

## プロットを書く

### カード

セリフ・モノローグ・ナレーション・ト書きを、1枚ずつカードに書きます。カードは、仕上がりのフキダシに近い形で表示されます。

| 種類 | 見た目 |
| --- | --- |
| セリフ | 丸いフキダシ |
| モノローグ | 点線の枠 |
| ナレーション | 四角い枠 |
| ト書き・メモ | 付箋 |

- **書く**: カードを押すと編集になります。ほかの場所を押すと編集が終わります。
- **追加**: 区切りの下にある「＋ セリフ」などのボタンで追加します。PCでは、編集中に Ctrl+Enter(Macは ⌘+Enter)を押すと、すぐ下に次のカードを追加できます。
- **種類と話者を変える**: カードの上の「朝比奈 湊 ・ セリフ」のような表示を押します。
- **並べ替え**: カードをつかんで動かします。スマホ・タブレットでは、長押しすると持ち上がります。別の区切りへも移せます。
- **複製・伏線・削除**: カードの「⋯」から行います。削除したあとすぐなら、「元に戻す」で戻せます。

### 区切り

起・承・転・結のように、カードをまとめる枠です。

- 名前は自由に変えられます。数も自由に増やせます(「＋ 区切りを追加」)。
- 見出しの空いているところをつかむと、区切りごと並べ替えられます。区切りの「⋯」にある「ひとつ前へ/後ろへ移動」でも動かせます。
- 「横に並べる」と「縦に並べる」で、区切りの並べ方を切り替えられます。
- 区切りの「⋯」から色を変えられます。

### まとめて入力

先に文章で書いておいたセリフを、まとめてカードにできます。

- 空行を1行はさむと、そこで別のカードに分かれます。
- `湊「いらっしゃいませ」` や `久世：……ああ` のように書くと、話者とセリフを自動で振り分けます。`(…)` で囲むとモノローグになります。

## 構成を確かめる

### ページ数

- タイトルの下の「全◯P」に、作品全体の予定ページ数を入れます。
- 区切りごとに予定ページ数を入れると、色分けのバーで割り振りが見えます。
- 予定を超えると、超えた分が赤く表示されます。「残り4P」「4Pオーバー」も表示します。

### 温度グラフ(二人の距離感)

- 区切りごとに、二人の距離感を0(遠い)〜10(近い)で付けて、折れ線で表示します。
- 点を上下にドラッグして付けます。いちばん近い区切りには印が付きます。
- 「温度グラフ」ボタンで表示・非表示を切り替えます。

### 伏線チェック

- カードの「⋯」→「伏線を付ける」で、そのカードで伏線を「張る」か「回収」するかを指定します。
- 「資料を横に出す」→「伏線」タブで、伏線ごとの状態を一覧で確認できます。
  - **回収済み** / **未回収** / **張っていない** / **回収が先**(張る前に回収している)
- 一覧の場所を押すと、そのカードへ移動します。
- 未回収の数は、「資料を横に出す」のボタンにも表示されます。

## キャラと設定

「キャラ・設定」タブで書きます。

- **キャラ**: 名前・よみ・立ち位置・年齢・身長・一人称・相手の呼び方・性格・外見・設定・メモ。画像は何枚でも入れられます(ドラッグ&ドロップでも追加できます)。キャラの色は、プロットの話者の表示にも使われます。
- **作品の設定**: 能力の決まりごとや世界観、舞台など、作品ごとの設定を書いておく場所です。

プロットを書きながら確かめたいときは、「資料を横に出す」を押します。キャラ・設定・伏線の3つのタブで横に表示されます(スマホでは下から出ます)。キャラのタブには、身長差も表示されます。

---

## 書き出し

右上の「書き出し」(スマホでは ⇩)から選びます。

### クリスタ用テキスト

- カードの順にテキストを並べ、カードごとに空行を1行はさみます。ストーリーエディターに貼るか、テキストファイルとして保存して読み込みます。
- 含めるカードの種類を選べます(ト書き・メモは最初から外してあります)。
- 確認用に、区切りの見出しや話者名を付けることもできます。ストーリーエディターに入れるときは外してください。

### PNG・PDF

- プロット・キャラと設定・両方から選んで書き出せます。
- プロットは「一覧(上から読む)」と「ボード(見たまま)」の2つの見た目から選べます。
- 温度グラフや伏線の一覧も入ります。
- PDFはA4サイズで、カードの途中でページが切れないように分けます。

## 作品の管理

作品名の横の「⋯」から行います。

- 新しい作品 / この作品を複製 / この作品を削除
- **バックアップを保存**: 全作品を1つのファイルに保存します。画像も入ります。
- **バックアップを読み込む**: 保存したファイルから作品を取り込みます。今ある作品は消えません。
- **表示の明るさ**: 端末に合わせる / ライト / ダーク(PCでは右上の ◐ ボタンからも選べます)

---

## 端末どうしの同期(Googleドライブ)

右上の「ドライブにつなぐ」を押してGoogleアカウントでログインすると、ほかの端末と同じ作品を編集できます。

- 一度つなぐと、編集するたびに自動で同期します。アプリを開いたときや、ほかのアプリから戻ってきたときにも同期します。
- ログインは1時間ほどで切れます。右上が「再接続」になったら押してください。それまでに書いた分は、端末の中に保存されています。
- データはGoogleドライブのアプリ専用の場所に入ります。ドライブの画面には表示されません。
- 同じ作品を2台で同時に書き換えた場合は、あとから保存したほうが残ります。
- ドライブにつながなくても使えます。その場合、データはその端末の中だけに保存されます。

---

## 困ったとき

- **データが消えた気がする**: 別の端末で書いた場合は、ドライブにつないで同期すると表示されます。ブラウザの閲覧データを消すと、その端末の中のデータも消えます。こまめに「バックアップを保存」しておくと安心です。
- **「新しい版があります」と出た**: 押すと最新の版に切り替わります。書いている内容はそのまま残ります。
- **スマホでカードが動かない**: 指を動かす前に、少し長めに押してください。すぐに動かすとスクロールになります。

---

## このアプリを置く人へ

- このフォルダの中身をGitHub Pagesなどに置くと、そのまま使えます。
- 同期を使うときは、`config.js` の `googleClientId` に、Google Cloudで作ったOAuthクライアントID(ウェブ アプリケーション、スコープ `drive.appdata`)を入れます。
- 中身を更新したら、`sw.js` の `VERSION` の数字を上げてください。開いている人に「新しい版があります」と表示されます。
