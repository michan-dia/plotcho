# プロット帖(Web版)

セリフやモノローグをカードで書いて並べ替える、漫画のプロット帳です。
ホーム画面(スマホ・タブレット)やアプリ一覧(PC)から、Claudeを開かずに直接起動できます。
Googleドライブで、端末どうしのデータを同期します。

---

## 全体の流れ

1. GitHub Pages に公開する(コマ帖と同じやり方)
2. config.js にクライアントIDを入れる(コマ帖と同じIDを使えます)
3. 各端末のホーム画面に追加する
4. Claude版のデータを引っ越す(使っていた場合)

---

## 1. GitHub Pages に公開する

1. GitHubで「New repository」を押し、Repository name を `plotcho` にします。**Public** を選び、「Add a README file」などのチェックは付けずに「Create repository」を押します。
2. できた空のリポジトリの画面で「uploading an existing file」を押し、このフォルダの**中身**を全部ドラッグします(`vendor` と `icons` はフォルダのままで大丈夫です)。下の緑の「Commit changes」を押します。
   - リポジトリのトップに `index.html` が直接並んでいれば成功です。`plotcho-web` というフォルダが1つだけ見えていたら、フォルダごと上げています。コマ帖のときと同じように、消して中身だけ上げ直してください。
3. 「Settings」→ 左メニューの「Pages」を開き、Source を **Deploy from a branch**、Branch を **main** と **/ (root)** にして「Save」を押します。
4. 1〜2分待つと、`https://(GitHubのユーザー名).github.io/plotcho/` で開けるようになります。

## 2. Googleドライブ同期を使えるようにする

コマ帖で作ったGoogleのクライアントIDを、そのまま使えます。プロット帖も同じ `https://(ユーザー名).github.io` から開くので、Google Cloud の設定を変える必要はありません。

1. コマ帖の `config.js` を開き、`googleClientId` に入っている文字列(`〜.apps.googleusercontent.com`)をコピーします。
2. このフォルダの `config.js` の `googleClientId: ''` の `''` の中に貼り付けます。
3. GitHubのリポジトリで「Add file」→「Upload files」から `config.js` を上げ直し、「Commit changes」を押します。

- データは、ドライブの中の「アプリ専用の場所」に入ります。ドライブの画面には出てきません。コマ帖のデータとは別のファイルなので、混ざりません。
- Googleのテストユーザーに追加してある人だけがログインできます(コマ帖と同じ)。
- 同期しないなら、この手順は飛ばしてかまいません。データはその端末の中にだけ保存されます。

### 同期のしかた

- 右上の「ドライブにつなぐ」を押すとGoogleのログイン画面が出ます。一度つなぐと、編集するたびに自動で同期します。
- ログインは1時間ほどで切れます。切れたら右上が「再接続」になるので、押してください。押すまでの間に書いたものも、端末の中には保存されています。
- アプリを開いたときや、ほかのアプリから戻ってきたときにも同期します。
- 同じ作品を2台で同時に書き換えた場合は、あとから保存したほうが残ります。

## 3. ホーム画面に追加する

- **iPhone・iPad(Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android(Chrome)**: 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
- **PC(Chrome・Edge)**: アドレスバーの右にあるインストールのボタン(またはメニューの「アプリをインストール」)

一度開いたあとは、ネットにつながっていなくても起動して書けます。同期は、つながったときに行われます。

## 4. Claude版から引っ越す

1. Claude版のプロット帖で、作品名の横の「⋯」→「バックアップを保存(全作品)」を押します。キャラの画像も入ります。
2. Web版のプロット帖で、同じく「⋯」→「バックアップを読み込む」を押して、そのファイルを選びます。

---

## 更新するとき

変わったファイルを、リポジトリの「Add file」→「Upload files」で同じ場所に上げ直します。
アプリは次に開いたときに新しい版を受け取り、「新しい版があります」と表示します。押すと切り替わります。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体(画面・見た目・動き) |
| `drive.js` | Googleドライブとの通信 |
| `config.js` | クライアントIDの設定 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `manifest.webmanifest`・`icons/` | ホーム画面に置いたときの名前とアイコン |
| `vendor/` | 並べ替え・画像書き出し・PDF書き出しのライブラリ |
